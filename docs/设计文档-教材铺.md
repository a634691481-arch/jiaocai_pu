# 教材铺 - 教材下载小程序设计文档

> 创建时间: 2026-06-11

## 1. 项目概述

将现有"挪车助手"项目改造为"教材铺"——面向 K-12 学生的教材下载微信小程序。核心功能：按年级/科目浏览和下载教材 PDF，通过激励视频广告变现。

## 2. 需求决策

| 决策项 | 选择 |
|--------|------|
| 教材资源来源 | 手动上传到 UniCloud 云存储 |
| 教材格式 | PDF + 封面图片 |
| 下载权限 | 游客可浏览，下载需登录 |
| 广告模式 | 激励视频广告（下载前观看）+ Banner 广告（页面底部） |
| 分类导航 | 按年级分组（小学1-6 / 初中7-9），进入后按科目筛选 |
| 页面架构 | 底部 3 Tab：首页 / 分类 / 我的 |

## 3. 页面结构

```
TabBar
├── 首页 (pages/index/index)
│   ├── 搜索框（全局搜索入口）
│   ├── Banner 轮播（公告/活动）
│   ├── 热门推荐列表（网格展示封面）
│   └── 底部 Banner 广告
│
├── 分类 (pages/category/index)
│   ├── 顶部年级 Tab 切换（小学1-6 / 初中7-9）
│   ├── 科目宫格入口（语文/数学/英语/...）
│   ├── 点击进入教材列表
│   └── 底部 Banner 广告
│
└── 我的 (pages/my/index)
    ├── 用户头像/昵称（登录入口）
    ├── 下载历史（分页列表）
    └── 其他菜单项

子页面（非 Tab）
├── 教材列表 (pages/textbook/list) — 按 grade + subject 分页查询
├── 教材详情 (pages/textbook/detail) — 封面大图 + 信息 + 下载按钮
└── 搜索结果 (pages/search/index) — 全局关键词搜索分页
```

## 4. 数据库设计

### 4.1 textbooks — 教材集合

| 字段 | 类型 | 说明 |
|------|------|------|
| _id | String | 自动生成 |
| title | String | 教材名称，如"语文 三年级上册" |
| grade | String | 年级编码: grade1~grade9 |
| subject | String | 科目编码: chinese/math/english/physics/chemistry/biology/politics/history/geography |
| publisher | String | 出版社，如"人教版" |
| cover | String | 封面图片 URL（云存储 CDN） |
| fileUrl | String | PDF 文件 URL（云存储 CDN） |
| fileSize | Number | 文件大小（字节） |
| downloads | Number | 下载次数 |
| views | Number | 浏览次数 |
| isHot | Boolean | 是否热门推荐 |
| status | Number | 0=下架, 1=上架 |
| addTime | Date | 添加时间 |

### 4.2 download_logs — 下载记录

| 字段 | 类型 | 说明 |
|------|------|------|
| uid | String | 用户 ID |
| textbookId | String | 教材 ID |
| title | String | 教材名称（冗余） |
| downloadTime | Date | 下载时间 |

### 4.3 banners — 首页 Banner

| 字段 | 类型 | 说明 |
|------|------|------|
| imageUrl | String | Banner 图片 |
| linkType | String | textbook / url |
| linkValue | String | 教材 ID 或外部链接 |
| sort | Number | 排序权重 |

### 4.4 年级/科目数据字典（前端硬编码）

**年级**: grade1~grade9
- 小学: grade1, grade2, grade3, grade4, grade5, grade6
- 初中: grade7, grade8, grade9

**科目**:
- 通用: chinese(语文), math(数学), english(英语)
- 初中增: physics(物理), chemistry(化学), biology(生物), politics(政治), history(历史), geography(地理)

## 5. 云函数 API

所有接口路径: `client/pub_index.xxx`

### 5.1 无需登录 (6个)

| 接口 | 说明 | 入参 |
|------|------|------|
| getTextbookList | 分页查询教材列表 | grade, subject, keyword, pageIndex, pageSize |
| getTextbookDetail | 获取教材详情 | id |
| getHotTextbooks | 热门推荐列表(首页) | limit(默认10) |
| searchTextbooks | 全局搜索 | keyword, pageIndex, pageSize |
| getBanners | 首页 Banner 列表 | 无 |
| incrementViewCount | 计数(浏览/下载) | id, type(download/view) |

### 5.2 需要登录 (2个)

| 接口 | 说明 | 入参 |
|------|------|------|
| getDownloadUrl | 获取下载链接+记录 | id → 返回 fileUrl |
| getMyDownloads | 我的下载历史 | pageIndex, pageSize |

## 6. 下载流程

```
详情页点击下载
    → 检查登录状态（未登录 → vk.navigateTo 登录页 → 登录成功返回）
    → 播放激励视频广告（wx.createRewardedVideoAd）
    → 广告播放完毕回调
    → 调用 getDownloadUrl 云函数
    → 获取 PDF 下载链接
    → wx.downloadFile({ url })
    → wx.openDocument({ filePath }) 打开预览
```

## 7. 广告集成

| 广告类型 | 位置 | 触发时机 | 广告单元 |
|----------|------|----------|----------|
| 激励视频 | 详情页 | 点击"下载"按钮，播放完毕后允许下载 | rewardedVideoAd |
| Banner | 首页/分类页底部 | 页面加载时自动展示 | bannerAd |

## 9. 技术约束

- 云函数单次执行超时 60s，PDF 文件不宜过大（<50MB）
- UniCloud 云存储流量免费额度有限，需关注使用量
- 微信小程序激励视频广告需在后台申请开通
- PDF 使用 `wx.openDocument` 预览，无需额外组件
- 必须使用 `vk.*` 封装 API 而非 `uni.*`
- 页面模板统一使用 `<yy-paging>` 作为根组件
