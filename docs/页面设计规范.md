## 2. 字体与排版

小程序仅支持系统字体。

```
字体: -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif

字号阶梯 (rpx):
  text-xs:    22rpx   辅助说明
  text-sm:    26rpx   标签、时间
  text-base:  30rpx   正文
  text-lg:    34rpx   小标题
  text-xl:    38rpx   大标题
  text-2xl:   44rpx   页面标题
  text-3xl:   52rpx   数字/Hero
```

间距基准 8rpx 栅格：`xs:8 / sm:16 / md:24 / lg:32 / xl:48 / 2xl:64`

圆角：`sm:8rpx / md:16rpx / lg:24rpx / full:9999rpx`

阴影：
- `shadow-sm`: 0 1rpx 3rpx rgba(0,0,0,0.06)
- `shadow-md`: 0 4rpx 12rpx rgba(0,0,0,0.08)
- `shadow-lg`: 0 8rpx 24rpx rgba(0,0,0,0.10)

## 3. 通用组件

### 3.1 封面卡片 (教材列表/推荐用)

```
┌──────────────┐
│              │  宽高比 3:4
│   封面图片    │  radius-md + shadow-sm
│              │  点击 scale(0.96) → 详情
├──────────────┤
│ 语文·三年级上  │  text-base font-medium
│ 人教版 12.5MB │  text-xs text-secondary
└──────────────┘
```

加载中 → 骨架屏; 加载失败 → 科目色底 + 书名

### 3.2 年级 Tab

横向滚动 `scroll-view`，选中态 `bg-primary` 白字，切换 `transition-all duration-200`。

### 3.3 科目宫格

3 列网格，gap 16rpx。每格 105×105rpx，科目浅色底 + 图标 + 文字。小学仅显示语数英 3 科。

### 3.4 搜索框

首页为静态卡片入口 (h:72rpx, radius-full)，点击跳搜索页。搜索页顶部聚焦输入 + 防抖 300ms。

## 4. 页面布局

### 4.1 首页 (pages/index/index)

```
┌──────────────────────┐
│  教材铺              │  Navbar
│  [搜索框入口]         │
├──────────────────────┤
│  [Banner 轮播]       │  swiper h:280rpx, 3s 自动
├──────────────────────┤
│  热门推荐    更多 >   │
│  ┌────┐ ┌────┐      │  2 列网格
│  │封面│ │封面│      │  上拉加载更多
│  └────┘ └────┘      │
├──────────────────────┤
│  [Banner 广告 120]   │  fixed bottom
└──────────────────────┘
```

### 4.2 分类页 (pages/category/index)

```
┌──────────────────────┐
│  分类                │
│  小学 ▾ 一年级 ...   │  小学/初中切换 + 年级Tab
├──────────────────────┤
│  ┌────┬────┬────┐   │
│  │语文│数学│英语│   │  科目宫格 3 列
│  └────┴────┴────┘   │  初中显示全部 9 科
├──────────────────────┤
│  [Banner 广告]       │
└──────────────────────┘
```

### 4.3 教材列表 (pages/category/list)

3 列网格，Navbar 带返回 + 动态标题 "三年级·语文"。

### 4.4 教材详情 (pages/category/detail)

```
┌──────────────────────┐
│     教材详情          │
│   ┌────────┐         │  封面大图 w:360 h:480
│   │ 封面   │         │  居中 shadow-lg
│   └────────┘         │
│ 语文·三年级上册        │  text-xl bold
│ 人教版               │  text-sm
│ ┌──────────────────┐ │
│ │ PDF·12.5MB  👀1234│ │  文件信息卡
│ └──────────────────┘ │
│ ┌──────────────────┐ │
│ │   📥 下载教材     │ │  绿色按钮 h:88rpx
│ │ 观看广告后免费下载 │ │  radius-full
│ └──────────────────┘ │
│ 相关推荐 → 3列横滑   │
└──────────────────────┘
```

下载按钮状态: idle → loading → downloading(进度条) → success(openDocument) → error(重试)

### 4.5 我的 (pages/my/index)

未登录：头像占位 + "点击登录" → 跳登录页
已登录：用户信息卡 + 下载历史分页列表

### 4.6 搜索页 (pages/index/search)

输入防抖 300ms → 3 列结果网格。空态显示 "未找到相关教材"。搜索历史存本地(最多 10 条)。

## 5. 动效

| 交互 | 效果 |
|------|------|
| 卡片点击 | `scale(0.96)` 100ms |
| 列表加载 | 骨架屏扫光 1.5s 循环 |
| 页面入场 | stagger 淡入上移 (delay 50ms) |
| 下载进度 | 按钮内进度条 primary → accent |
| 页面转场 | push 右→左 300ms, pop 左→右 300ms |

---

## 6. 适配

- 基准 750rpx，底部 `safe-area-inset-bottom`
- `u-navbar` 自定义导航栏，首页透明→滚动白底
- 广告位 fixed bottom，内容区 `padding-bottom: 120rpx`
