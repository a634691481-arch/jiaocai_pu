# 教材宝 项目概览

## 项目简介

**教材宝** 是一个基于 uni-app + Vue 3 + Vite 的跨平台小程序项目，原生目标为**微信小程序 (mp-weixin)**，同时支持 H5 和 App 端。

## 项目信息

| 属性 | 内容 |
|------|------|
| 项目名称 | 教材宝 |
| 框架 | uni-app (Vue 3) + Vite |
| 版本 | 0.0.22 (build 33) |
| 云服务 | UniCloud (阿里云) |
| 开发工具 | HBuilderX |
| 包管理器 | pnpm |

## 技术栈

| 层次 | 技术 |
|------|------|
| 前端框架 | Vue 3 + uni-app (Vite) |
| UI 库 | uView Pro (`uni_modules/uview-pro`) |
| 云函数框架 | VK UniCloud (`uni_modules/vk-unicloud`) |
| 分页组件 | z-paging (`uni_modules/z-paging`)，包装为 `yy-paging` |
| 样式方案 | TailwindCSS 3.4 + SCSS，通过 `weapp-tailwindcss` 适配小程序 |
| 状态管理 | Vuex 4，自动持久化到 `uni.getStorageSync('lifeData')` |
| 图标方案 | Iconify (`@iconify/vue`)，通过 `yy-icon` 组件封装 |
| 动画 | `@formkit/auto-animate` |
| 加密 | `crypto-js` + `js-md5` |

## 目录结构

```
├── apis/                     # HTTP REST API 层

│   └── cloudfunctions/router/# 云函数路由入口 + 业务逻辑
├── uni_modules/              # uni-app 插件市场组件
├── app.config.js             # VK 框架配置
├── pages.json                # 页面路由 + easycom
├── vite.config.js            # Vite 构建配置
└── tailwind.config.js        # TailwindCSS 主题配置
```

## 构建与开发

- **开发运行**：在 HBuilderX 中打开项目 → 点击"运行" → 选择目标平台
- **生产发布**：HBuilderX → "发行" 菜单
- **云函数上传**：`npm run upload`（执行 `node scripts/upload.js`）
- **postinstall**：`pnpm install` 自动触发 `weapp-tw patch`
- **环境变量**：`VITE_API_BASE_URL` 定义在 `.env.development` / `.env.production`

## 核心功能

项目基于 VK UniCloud 框架 + HTTP REST API 双通道架构：
- 核心业务逻辑通过 **VK 云函数** (`vk.callFunction`) 调用
- 外部集成（微信登录、手机号获取）通过 **HTTP REST API** (`api.xxx`) 调用
- 用户登录使用 `vk.userCenter.loginByWeixin()`（VK 框架内置微信 OAuth）
