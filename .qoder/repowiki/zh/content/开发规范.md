# 开发规范

## 页面模板规范

所有页面统一使用 `yy-paging`（z-paging 封装）作为根容器：

```vue
<yy-paging v-model="state.dataList" @query="queryList" ref="paging" @scroll="scroll" v-bind="pagingConfig">
  <view class="page-content">
    ... 页面内容 ...
  </view>
</yy-paging>
```

**核心规则：**
1. 配置集中在 `pagingConfig` 对象，通过 `v-bind="pagingConfig"` 展开
2. `queryList(page, limit)` 为 async 函数，接收分页参数
3. 云函数调用统一 `vk.callFunction({ url: 'client/xxx.xxx', data: {} })`
4. 加载完成必须调 `paging.value?.complete(data[])`
5. 非列表页设 `auto: false, loadingMoreEnabled: false`

## VK API 使用规范

**必须使用 VK 封装的 API 替代 uni-app 原生 API：**

| 场景 | VK 封装 | 原生替代品 |
|------|---------|-----------|
| 页面跳转 | `vk.navigateTo` | `uni.navigateTo` |
| 重定向 | `vk.redirectTo` | `uni.redirectTo` |
| 重载 | `vk.reLaunch` | `uni.reLaunch` |
| Tab 切换 | `vk.switchTab` | `uni.switchTab` |
| Toast 提示 | `vk.toast` | `uni.showToast` |
| 加载中 | `vk.showLoading` / `vk.hideLoading` | `uni.showLoading` |
| 对话框 | `vk.alert(content, title, confirmText, callback)` | `uni.showModal` |
| 确认框 | `vk.confirm({...})` | `uni.showModal` |
| 存储 | `vk.setStorageSync` / `vk.getStorageSync` | `uni.setStorageSync` |
| Vuex | `vk.vuex.set` / `vk.vuex.get` | Vuex 原生 API |
| 云函数 | `vk.callFunction` | `uniCloud.callFunction` |

**注意：** `vk.alert` 接收**分开的字符串参数**，不是对象：
```js
// ✅ 正确
vk.alert('内容', '标题', '我知道了', () => {})
// ❌ 错误
vk.alert({ content: '内容', title: '标题' })
```

## 编码规范

- **语言**：代码注释以中文为主
- **样式**：优先使用 TailwindCSS 类名，复杂样式用 SCSS
- **图标**：使用 Iconify 图标名（如 `ri:home-smile-2-line`），通过 `<yy-icon>` 组件渲染
- **格式化**：使用 Prettier（配置见 `.prettierrc`）
- **自动导入**：Vue 和 uni-app 的 API（ref, computed, onLoad 等）无需手动 import

## 云函数开发规范

- 业务逻辑写在 `service/client/` 目录下
- 数据访问使用 DAO 层（`dao/modules/`）
- 返回格式：`{ code: 0, msg: '', data: {} }`
- 错误返回：`{ code: -1, msg: '错误描述' }`
- 中间件在 `middleware/modules/` 目录下，按 `index` 排序执行
