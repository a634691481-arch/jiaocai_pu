# 项目设置与命令

## 开发环境

- **运行方式**：HBuilderX → 打开项目 → 运行 → 选择目标平台
- **构建发布**：HBuilderX → 发行菜单
- **包管理器**：pnpm
- **postinstall**：自动执行 `weapp-tw patch`（TailwindCSS 小程序适配补丁）

## 命令

```bash
# 云函数上传
npm run upload      # 执行 node scripts/upload.js

# 测试（未配置）
npm test            # 仅输出 "Error: no test specified"
```

## 环境变量

| 文件 | 用途 | 值 |
|------|------|-----|
| `.env.development` | 开发环境 | `VITE_API_BASE_URL=http://120.53.10.90:8963` |
| `.env.production` | 生产环境 | `VITE_API_BASE_URL=https://api.manpsychology.com` |

## 关键配置

| 文件 | 用途 |
|------|------|
| `app.config.js` | VK 框架配置：登录页、CDN、Token 检查模式、错误处理 |
| `manifest.json` | 小程序 appid、版本号、App 模块权限 |
| `pages.json` | 页面路由 + easycom 模式 + 全局样式 |
| `vite.config.js` | Vite 插件：uni、tailwind、auto-import、code-inspector |
| `tailwind.config.js` | Tailwind 主题色（通过 CSS 变量关联 uView Pro 主题） |
| `theme.json` | 微信小程序暗黑模式颜色配置 |
