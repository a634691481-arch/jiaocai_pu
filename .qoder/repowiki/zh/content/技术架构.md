# 技术架构

## 整体架构

教材铺采用 **前后端分离 + 云函数** 架构：

```
[前端] uni-app (Vue3)
   ├── vk-navigateTo → [Token检查] → [页面]
   ├── vk.callFunction → [UniCloud 云函数 router]
   └── uni.$u.http → [HTTP REST API 外部服务]
```

## 双 API 通道

### 1. VK 云函数（主通道）
- 核心业务逻辑全部走 VK 云函数
- 调用方式：`vk.callFunction({ url: 'client/xxx.xxx', data: {} })`
- 路由入口：`uniCloud-aliyun/cloudfunctions/router/index.js`
- 单一云函数 `router` 通过 `vk.router()` 分发请求

### 2. HTTP REST API（次通道）
- 用于微信 OAuth 登录等外部集成
- base URL：`https://travel.tasiai.cn/h5/api/tasi_travel_manage_system_prod`（prod）
- 调用方式：`api.getOpenid()`, `api.getPhoneNumber()`, `api.getUserInfo()`
- 统一错误处理，支持"复制错误"到剪贴板

## 前端构建流程

```
Vite + @dcloudio/vite-plugin-uni
  ├── autoPagesJson()          - 自动生成 pages.json
  ├── codeInspectorPlugin()    - 代码审查插件
  ├── uvwt()                   - weapp-tailwindcss 适配
  ├── AutoImport()             - 自动导入 Vue/uni-app API
  ├── UniRoot()                - uni-app 根组件
  └── uni()                    - 核心 uni 插件
```

## 状态管理

Vuex 4 实现，自动持久化到 `localStorage`（key: `lifeData`）：
- `$user` — 用户信息、权限、邀请码
- `$app` — 应用初始化、网络状态、颜色配置
- `$tabbar` — 自定义 Tabbar 配置
- `$error` — 唯一不持久化的模块（仅 `notSaveStateKeys` 排除）

## 主题系统

uView Pro 主题引擎 + CSS 变量，9 套预设主题：
- 默认主题：`green`（清翠绿）
- 通过 `uni.$u.color.primary` 等访问颜色值
- TailwindCSS 扩展色通过 CSS 变量关联（`--color-primary` 等）

## 页面路由与权限

- `app.config.js` 中 `checkTokenPages.mode: 2` — list 外的页面需要登录
- 免登录白名单：`/pages/index/*`, `/pages/login/index`, `/pages/product-intro/*`
- 必须使用 `vk.navigateTo` 才能使 token 检查生效
- Tabbar 页面需要手动调用 `vk.pubfn.checkLogin()`

## 组件注册

通过 `pages.json` 的 easycom 自动注册：
- `^yy-(.*)` → `@/components/yy-$1.vue`（业务组件）
- `^u-(.*)` → `@/uni_modules/uview-pro/components/u-$1/u-$1.vue`（uView Pro 组件）
- `unplugin-auto-import` 自动导入 `vue` 和 `uni-app` API
