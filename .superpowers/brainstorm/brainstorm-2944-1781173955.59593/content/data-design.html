数据库设计

UniCloud 阿里云 MongoDB — 3个核心集合

📗 textbooks — 教材集合

字段类型说明
_idString自动生成
titleString教材名称，如"语文 三年级上册"
gradeString年级，如 grade3
subjectString科目，如 chinese/math/english
publisherString出版社，如"人教版"
coverString封面图片URL（云存储）
fileUrlStringPDF下载地址（云存储CDN）
fileSizeNumber文件大小（字节）
downloadsNumber下载次数
isHotBoolean是否热门推荐
statusNumber0=下架 1=上架
addTimeDate添加时间

📘 download_logs — 下载记录

字段类型说明
uidString用户ID
textbookIdString教材ID
titleString教材名称（冗余，方便展示）
downloadTimeDate下载时间

📒 banners — 首页公告/Banner

字段类型说明
imageUrlStringBanner图片
linkTypeStringtextbook / url
linkValueString教材ID 或 外部链接
sortNumber排序权重

年级/科目 数据字典（前端硬编码）

年级: grade1~grade9（一年级~九年级），按小学/初中分组
科目: chinese / math / english / physics / chemistry / biology / politics / history / geography
