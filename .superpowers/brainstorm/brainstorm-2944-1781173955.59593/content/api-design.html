📗 教材相关 (5个)

接口说明入参
getTextbookList分页查询教材列表grade, subject, keyword, pageIndex, pageSize
getTextbookDetail获取教材详情id
getHotTextbooks热门推荐列表(首页)limit (默认10)
searchTextbooks全局搜索keyword, pageIndex, pageSize
getDownloadUrl获取下载链接(需登录)id → 返回 fileUrl + 计入下载记录

📒 其他 (3个)

接口说明入参
getBanners首页Banner列表无
getMyDownloads我的下载历史(需登录)pageIndex, pageSize
incrementViewCount增加浏览/下载计数id, type(download/view)

🔑 权限说明

详情页 → 点击下载 → 检查登录 → 未登录跳转 → 播放激励视频广告 → getDownloadUrl → 返回PDF链接 + 记录下载 → 调用wx.downloadFile + wx.openDocument
